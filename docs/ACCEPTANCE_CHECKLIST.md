# ชุดตรวจรับงาน GenieAI (ให้เจ้าของคลินิกลองก่อนเปิดใช้จริง)

ใช้เวลาประมาณ 20–30 นาที ใช้ LINE จริงของคุณคุยกับบอท แล้วติ๊กผลทีละข้อ
ถ้าข้อไหน "ไม่ผ่าน" ให้จดข้อความที่บอทตอบ (หรือแคปหน้าจอ) ส่งให้ทีมพัฒนา

## ส่วน A: ส่งรูปและสติกเกอร์ (ผมทดสอบเองไม่ได้)

ทำจากมือถือที่ LINE ใช้งานได้ ในแชตกับบอท

| # | ทำอะไร | ควรเห็น | ผ่าน |
|---|---|---|---|
| A1 | ส่งสติกเกอร์ 1 ตัว | บอทเงียบ หรือตอบสุภาพ ไม่ตอบเป็นข้อความแปลกๆ ไม่มี error | ☐ |
| A2 | ส่งรูปถ่ายฟัน 1 รูป | บอทเงียบ หรือแจ้งว่าดูรูปไม่ได้/ให้ติดต่อเจ้าหน้าที่ ไม่เดาโรคจากรูป | ☐ |
| A3 | ส่งรูปแล้วพิมพ์ต่อ "ขอจองคิวหน่อยค่ะ" | บอทกลับมาตอบปกติและถามข้อมูลการจอง | ☐ |
| A4 | ส่งไฟล์ PDF 1 ไฟล์ | บอทไม่พัง ข้อความถัดไปยังตอบปกติ | ☐ |
