1. ภาพรวมโครงการ (เล่าคร่าวๆ)
================================================================================

GenieAI คือระบบ "ผู้ช่วยธุรกิจอัจฉริยะแบบ Multi-tenant SaaS" สำหรับเจ้าของธุรกิจ
ขนาดเล็ก-กลาง เช่น ร้านทำผม คลินิกความงาม สปา ร้านอาหาร

แนวคิดหลัก:
  เจ้าของร้านแค่อัปโหลดคู่มือบริการ (PDF/TXT/MD) -> ระบบใช้ AI สร้างแชตบอท
  อัตโนมัติ -> ลูกค้าทักแชทเข้ามาถามข้อมูลและจองนัดหมายได้เอง ผ่าน LINE
  (รวมถึง Facebook / Web Chat ในอนาคต)

ผู้ใช้งาน 2 กลุ่ม:
  - แอดมิน (เจ้าของร้าน): ใช้ Dashboard จัดการข้อมูลร้าน ดูคิวนัดหมาย ทดสอบ AI
  - ลูกค้าปลายทาง: แชทกับ AI ผ่าน LINE เพื่อสอบถามและจองคิว

หัวใจทางเทคนิค:
  - Backend: FastAPI (Python 3.11) + OpenAI GPT-4o-mini
  - Frontend: React 19 + Vite 8 + Tailwind v4 + HeroUI (ดีไซน์ Glassmorphism
    โทน Navy-Cyan)
  - เครื่องมือ AI: Hybrid RAG + CAG engine (เอกสารเล็กยัดเข้า prompt ทั้งก้อน /
    เอกสารใหญ่ค้นเวกเตอร์ใน ChromaDB), Vision OCR อ่านเอกสารภาษาไทย,
    Redis เก็บประวัติแชต
  - จุดเด่น: ตอบแบบ multi-bubble หน่วงเวลา 2-4 วินาที เลียนแบบคนพิมพ์จริง +
    จองคิวอัตโนมัติผ่าน AI Function Calling

สถานะปัจจุบัน: เป็น Prototype แบบ Single-tenant ที่ใช้งานได้จริง end-to-end
บน LINE แล้ว

2. KPI คืออะไร (ตัวชี้วัดความสำเร็จ)
================================================================================

ก) KPI เชิงธุรกิจ (Business)
  - อัตราการจองสำเร็จผ่านบอท (Booking Conversion):
        ลูกค้าจองจบในแชตได้เองโดยไม่ต้องให้คนช่วย
  - สัดส่วนคำถามที่บอทตอบได้เอง (Self-service rate):
        ลดภาระแอดมินตอบแชตเอง
  - เวลา Onboarding ร้านใหม่:
        อัปโหลดคู่มือ -> ใช้งานได้ ภายในไม่กี่นาที
  - ความเป็นธรรมชาติของบทสนทนา:
        ลูกค้ารู้สึกเหมือนคุยกับคนจริง

ข) KPI เชิงเทคนิค (System SLA - อ้างอิงค่าคงที่จริงในระบบ)
  - ความแม่นยำการจอง (No Double Booking): กันคิวซ้อน 30 นาที ต่อพนักงาน 1 คน
  - โหมดตอบข้อมูล:                        สลับ RAG/CAG ที่ threshold 15,000 tokens
  - ความเป็นมนุษย์ของการตอบ:              แบ่งสูงสุด 5 bubbles, หน่วง 2-4 วินาที/bubble
  - ความต่อเนื่องบทสนทนา:                 จำประวัติ 10 ข้อความ / เก็บนาน 2 ชั่วโมง
  - ประสิทธิภาพการอ่านข้อมูล:             แคชโปรไฟล์ร้าน 10 นาที (ลดการอ่าน disk)
  - ความปลอดภัย Webhook:                  ตรวจ HMAC-SHA256 ทุก request 100%

ทำเสร็จและใช้งานได้จริง:

  [x] LINE Chatbot ทำงาน end-to-end เต็มรูปแบบ
      - multi-bubble messaging, หน่วงเวลาแบบมนุษย์, push message fallback

  [x] Hybrid RAG + CAG context engine
      - สลับโหมดตามขนาดคลังข้อมูลอัตโนมัติ

  [x] ระบบจองคิวอัตโนมัติ ผ่าน AI Function Calling
      - check_booking_availability + create_booking พร้อมเช็คคิวซ้อน

  [x] Document Parsing
      - อัปโหลด PDF/TXT/MD -> Vision OCR (รองรับภาษาไทย/ตาราง)
        -> index เข้า ChromaDB -> สกัด business rules ด้วย GPT-4o-mini

  [x] Rich Tenant Profile
      - services, promotions, staff, FAQ โหลดเข้า system prompt แบบ dynamic

  [x] Dashboard (Frontend) 4 หน้าหลัก
      - หน้าภาพรวม (stat cards + webhook URL + นัดหมายล่าสุด)
      - คู่มือ & บริการ (แก้โปรไฟล์ + จัดการเอกสาร)
      - นัดหมายลูกค้า (ปฏิทิน + ค้นหา + filter)
      - กล่องทดสอบแชต (Chat + แผง AI Diagnostics: โหมด RAG/CAG, citations, รูป)

  [x] Design System
      - Glassmorphism โทน Navy-Cyan, dark/light theme, ภาษาไทยเต็มระบบ

  [x] ความปลอดภัยพื้นฐาน
      - HMAC signature verification + threading.Lock() กัน race condition
        บนไฟล์ JSON
